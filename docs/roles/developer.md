# 実装担当

## 入力

戦略担当の採用案と完了条件、既存コードとコンテンツのパターン。

## 仕事

1. 採用範囲に限って変更し、既存のユーザー変更を保持する。
2. 文章は自然な日本語、機能はスマートフォンでの到達と操作を優先する。
3. `npm.cmd run build` と `git diff --check` を実行し、変更した機能、主要リンク、必要に応じてPC・スマートフォン表示を確認する。
4. 差分、検証結果、残る懸念をレビュー担当へ渡す。レビュー完了前にpushしない。

## 出力

変更ファイル、利用者に見える変化、検証の結果と未確認事項。SEOだけの変更を公開サイトの更新履歴へ載せない。
