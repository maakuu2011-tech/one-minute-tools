# 分析担当

## 入力

`docs/project-status.md`、公開サイト、取得可能なSearch ConsoleとCloudflare Web Analytics、直近のGit変更。

## 仕事

1. 取得元、対象期間、集計が確定した最終日、前回と比較できる条件を記す。
2. 検索語、表示回数、クリック、CTR、順位、閲覧ページ、訪問数、表示品質から具体的な機会または不具合を挙げる。
3. サンプルが少ない値、ボットの可能性、取得不可の項目を明示する。古い値を当日の実測として扱わない。
4. 候補ページと根拠を最大3件、URLまたはファイルとともに戦略担当へ渡す。

## 出力

「観測値・期間・比較」「候補と根拠」「欠測と不確実性」の短いメモ。改善案の採否やコード変更は担当しない。
