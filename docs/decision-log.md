# 運営の意思決定ログ

日々の計測値は `docs/project-status.md` または日次レポートに記す。ここには、今後の優先順位や収益化方針が変わる判断だけを追加する。

## 2026-10-14: 日次運営を4役で確認する

- 決定: 分析、戦略、実装、レビューの出力を順に受け渡し、公開前にレビューを通す。
- 理由: 計測の解釈、改善対象の選択、実装、公開判断を同じ手順の中で明確にするため。
- 運用: 進行役が実装し、分析・戦略・レビューをプロジェクト内の専任サブエージェントに渡す。使えない場合は独立レビュー未実施を報告する。
- 再評価: 週次確認で所要時間、指摘の有用性、公開後の不具合を見て手順を調整する。
